# Meetinganmeldung, Club 41

Anmeldung der Mitglieder des Club 41 Grieskirchen-Hausruck zu einem Meeting, zuerst zum Ganserl-Meeting mit
Neuaufnahmen am 12. November 2026. Veröffentlicht über GitHub Pages, gebaut nach dem Muster von `c41-filzmoos`.

Das Mitglied wählt „Ich bin gerne dabei und esse ein Ganserl“, „Ich bin gerne dabei und esse à la carte“ oder
„Ich kann nicht dabei sein“, prüft die Auswahl und schickt sie an die Google-Web-App „C41 Meetinganmeldung“
(Konstante `GOOGLE` in `index.html`, Quelle `03 Bereiche/Club C41/Meetinganmeldung/Google/Code.gs` im Vault).
`MEETING` ist das Datum, unter dem die Antwort abgelegt wird. Für ein späteres Meeting `MEETING`, Texte und Bild
ändern; die persönlichen Links bleiben gültig.

Persönlicher Link: `?m=Nr.%2018%20Meissl&n=Hanspeter`. Den Link schickt Hanspeter per WhatsApp; „Einloggen“ auf
der Clubseite schickt ihn erneut an die hinterlegte Adresse.

Nichts Geheimes in dieses Repository: Es ist öffentlich. Die Adresse der Web-App darf hinein, der Exportschlüssel nie.
